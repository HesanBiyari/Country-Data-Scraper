# 🌍 Country Data Scraper

A Python web scraping project that collects country information from [Scrape This Site](https://www.scrapethissite.com/pages/simple/) and stores the data in an SQLite database.

## 🚀 Features

- Scrapes information from the first 20 countries
- Collects country name, capital, population, and area
- Stores the data in an SQLite database
- Displays the first 5 countries
- Calculates the total population of the collected countries

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- SQLite3
